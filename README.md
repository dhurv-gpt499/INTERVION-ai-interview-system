## ?? INTERVION 2.0: The WebSockets Migration

INTERVION has been completely rewritten from the ground up for V2! We stripped out the legacy Gradio UI, removed the clunky Python threading, and replaced local hardware `PyAudio` hooks with a modern, decoupled web architecture.

- **FastAPI + WebSockets:** No more UI polling. The server pushes audio, transcripts, and state changes instantly over a bidirectional WebSocket.
- **Browser Audio Capture:** Audio is captured natively in the browser via WebRTC `MediaRecorder` and streamed to the server. You can now host INTERVION on a remote cloud server!
- **Asyncio Pipeline:** The backend is 100% `async/await`, eliminating deadlocks and freezing.
- **Cloud STT Support:** You can now run Speech-to-Text via Groq`s insanely fast cloud Whisper API, meaning you no longer strictly need a powerful local GPU to get real-time response speeds.

## Tech Stack

| Layer | Technology | Purpose |
|---|---|---|
| **Frontend** | Vanilla JS + Tailwind | Lightweight, responsive browser interface |
| **Backend** | FastAPI + WebSockets | High-performance async server and event streaming |
| **STT** | faster-whisper / Groq API | Real-time speech to text (with cloud offloading option) |
| **VAD** | Silero VAD | Voice activity + pause detection (tensor-gated) |

| **TTS** | Edge-TTS | Natural streaming voice output sent as binary chunks |

## Installation & Running

1. **Clone the repository & install dependencies**
```bash
git clone https://github.com/dhurv-gpt499/INTERVION-ai-interview-system.git
cd INTERVION-ai-interview-system
pip install -r requirements.txt
```

2. **Add your API Keys**
Create a `.env` file in the root directory and add your Groq API key (optional, used if you select "Cloud API" in the setup screen):
```
GROQ_API_KEY=your_key_here
```

3. **Start the FastAPI Server**
```bash
uvicorn server.main:app --reload
```

4. **Open the App**
Open your web browser and navigate to `http://localhost:8000`.
