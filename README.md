## What is INTERVION?

INTERVION is a fully local, real-time AI interview simulator built for developers and students preparing for technical interviews.

It doesn't just ask questions — it **listens actively**, **detects how you feel**, and **adapts in real time**.

- Missed a beat? It comforts you.
- Answered confidently? It goes deeper.
- Froze mid-sentence? It gives you space.

Everything runs **locally on your machine** — no cloud APIs, no data leaving your system, no subscriptions.

## Features

- 🎙️ **Real-Time Speech Recognition** — Whisper-powered STT with Hinglish support
- 🧠 **Intelligent Questioning** — Resume-aware questions generated by Qwen 2.5 7B with Principal Engineer persona
- 📚 **Two-Engine Domain RAG** — Zero-VRAM keyword indexing across 22 rubrics & 50 target companies with 1.5x priority boosting
- 🧮 **Quant & Finance Brainteasers** — Dedicated logic, expected value, Fermi estimation, and game theory competencies
- 💬 **Streaming AI Responses** — LLM output fed token-by-token directly into TTS with silence-aware Mentor Mode
- 🎧 **Natural Voice Output** — Professional AI interviewer voice via Edge-TTS
- 👁️ **Emotion & Posture Detection** — Real-time anxiety and confidence scoring from MediaPipe facial landmarks
- ⏸️ **Pause-Aware Pipeline** — VAD detects hesitation, silence, and answer completion
- 📊 **Post-Interview Report Card** — Structured JSON evaluation with executive summaries, verdicts, and topic breakdowns
- 🔄 **Cross-Session Memory** — SQLite tracking across multiple interviews, archiving scores and transcripts
- 🗂️ **Resume Parsing** — Automatic extraction of skills, projects, and experience from PDF using Docling
- 🔒 **100% Local GPU Inference** — All LLM, STT, and Vision models run offline on your machine

## Tech Stack

| Layer | Technology | Purpose |
|---|---|---|
| **STT** | faster-whisper (small) | Real-time speech to text |
| **VAD** | Silero VAD | Voice activity + pause detection (tensor-gated) |
| **LLM** | Qwen 2.5 7B via Ollama | Technical interview intelligence & reasoning |
| **TTS** | Edge-TTS | Natural streaming voice output (on_audio_start sync) |
| **Vision** | OpenCV + MediaPipe | Webcam facial landmarks + emotion metrics |
| **RAG** | Scikit-Learn TF-IDF | Zero-VRAM keyword & concept context retrieval |
| **DB** | SQLite | Session analytics + cross-interview progress |
| **Audio** | PyAudio + pygame | Mic capture + low-latency audio playback |

**VRAM Budget (RTX 3050 6GB)**
```
faster-whisper small  →  ~1.0 GB
Qwen 2.5 7B Q4_K_M    →  ~4.3 GB
Vision (CPU)          →   0.0 GB
TTS (CPU)             →   0.0 GB
Total                 →  ~5.3 GB ✅
```

## Installation

> **Strict Requirement: Python 3.11 or Python 3.12** — everything else installs automatically.

```cmd
:: 1. Clone the repository
git clone https://github.com/yourusername/INTERVION.git
cd INTERVION

:: 2. Run the automated setup checklist and installer
python setup.py
```

**What `setup.py` / `setup.bat` does automatically:**
- ✅ Verifies compatible Python version (Strictly 3.11 or 3.12)
- ✅ Checks GPU CUDA status and Ollama service connection
- ✅ Pulls Qwen 2.5 LLM model (`qwen2.5:latest`)
- ✅ Configures isolated Python virtual environment (`interview_ai`)
- ✅ Safely installs PyTorch 2.4+ with CUDA 12.4 support (`--index-url https://download.pytorch.org/whl/cu124`)
- ✅ Installs all audio, vision, STT, and UI packages without dependency conflicts
- ✅ Automatically launches the INTERVION interface (`python ui/app.py`)

To manually launch the application after setup:
```cmd
call interview_ai\Scripts\activate.bat
python ui\app.py
```

## How It Works

```
1. Upload your resume (PDF)
        ↓
2. Qwen parses resume → extracts skills, projects, experience
        ↓
3. System prompt built with your full profile
        ↓
4. Interview begins — AI asks tailored question via TTS
        ↓
5. You answer via microphone
        ↓
6. Whisper transcribes in real-time chunks
        ↓
7. VAD detects answer completion (3s pause)
        ↓
8. Qwen evaluates answer → streams follow-up/next question
        ↓
9. TTS speaks response sentence by sentence
        ↓
10. Vision pipeline tracks anxiety + confidence throughout
        ↓
11. Post-interview: detailed feedback report generated
```
